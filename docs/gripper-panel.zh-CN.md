# 夹爪控制与从臂慢速归位窗口

双击仓库根目录 `open_gripper_panel.cmd`，或在 PowerShell 运行：

```powershell
Set-Location E:\Dobot\dobot-atomic-skills
E:\Dobot\.venv\Scripts\python.exe -X utf8 -B tools\gripper_panel.py
```

选择“左夹爪”或“右夹爪”，再点“全开”或“全闭”。用户已确认 255 全开、0 全闭；速度固定为 10。只提供全行程控制。

窗口下方新增两个独立按钮：**左臂慢速归位**、**右臂慢速归位**。点击对应按钮即可操作该侧，不需要先选上面的夹爪。

| 窗口标签（实体侧） | 当前 INI 段 | 当前端口/ID | 对应从臂 |
| --- | --- | --- | --- |
| 左夹爪 LEFT | GRIPPER_LEFT | COM3 / ID21 | 192.168.5.2 |
| 右夹爪 RIGHT | GRIPPER_RIGHT | COM4 / ID22 | 192.168.5.1 |

端口、ID 和行程每次打开窗口时从 `scripts/dobot_config/dobot_settings.ini` 读取；左右标签采用当前装置实体对应关系。窗口启动和侧别选择不连接硬件。点击夹爪动作后才申请共享设备锁、连接选定夹爪；构造沿用现有驱动的通信检查与扭矩限制设置，不创建机械臂客户端。

## 单侧从臂慢速归位

1. 停止跟随与录制，退出遥操 A/B 及其他机器人控制程序，结束 DobotStudio 控制连接。两柜处于 TCP/IP 二次开发模式。
2. 确认选定臂到 home 的路径空闲、夹爪无持物，再点击对应归位按钮。窗口只连接该侧的 Dashboard（29999）与运动端口（30003）；不会构造原有双臂服务，也不会打开夹爪串口或执行夹爪启动往返。
3. 窗口读当前 J1～J6 并对关节直线插值路径执行现有 FK 工作区/J3 预检；路径不通过则显示拒绝点。当前位置或路径超界时，需要现场先用已确认方式调整姿态，不自动扩大范围。
4. 当前处于禁用状态时会使能选定臂；报警、拖拽或已有任务运行时拒绝开始，不自动清报警。按 **0.15 rad/s** 上限、**0.05 s** 周期发送小步 ServoJ（每步最大约 **0.43°**），逐步检查实际反馈及工作区。实际角落后上一指令超过 5° 时中止。
5. 最终六轴误差均 ≤0.1°，且控制柜处于空闲使能状态连续确认 3 次后，窗口显示“已归位”和六轴读回值；最终反馈最多额外等待 10 秒。已在容差内时只读检查，不使能或发运动。

| 按钮 / 实体侧 | IP | home J1～J6（度） |
| --- | --- | --- |
| 左臂慢速归位 | 192.168.5.2 | -90, 0, -90, 0, 90, 90 |
| 右臂慢速归位 | 192.168.5.1 | 90, 0, 90, 0, -90, -90 |

IP 和 home 直接读取 `task_skills/layout.py`。归位保留夹爪当前开合状态；不改变工具、零位、标定或全局速度设置。新入口不依赖 `DOBOT_ALLOW_SAFE_POSE_INIT` 环境变量，点击对应归位按钮即明确启动该侧操作。归位完成后保持选定臂的使能状态，关闭窗口只断开网络连接。

归位期间可点 **停止归位**，工作线程在当前网络操作返回后停止继续发步，并向选定臂发送 `ResetRobot()`，检查返回状态。TCP 调用有等待时间，实体急停仍按现场操作处理。异常也会停止；停止无法确认时窗口报告原因并保留共享设备锁，需现场核验后按手册 11.2 处理。

夹爪动作只发送一次，读取反馈确认到位（误差 ≤5），最多等待 10 秒；失败不自动重试。夹爪动作与从臂归位共用忙碌状态和设备锁，执行期间其余动作按钮均禁用；只在归位期间开放“停止归位”。结束后关闭本次连接并释放本次申请的锁（停止未确认时保留锁）。关闭空闲窗口不发送开合或运动命令；动作期间需等待当前结果后关闭。

使用前停止跟随并退出遥操 A/B。窗口遵守 `DOBOT_DEVICE_LOCK_PATH`；未设置时使用 `E:\Dobot\.local\runtime\device-owner`，与本机遥操手册相同。若提示存在保留锁，按主操作手册 11.2 核对所有者并归档已退出进程留下的锁，窗口不自动删除锁。动作会保留 scene-invalid 标记，后续切换网关时按其流程复位场景。

错误直接显示在窗口，详细日志位于仓库 `.local/gripper-panel.log`。软件使用 Python 自带 Tkinter，无需安装额外 GUI 包。双击入口按“仓库在工作区子目录、.venv 在其上一级”的布局寻找 Python；其他布局可用 PowerShell 指定实际解释器运行。

实现：`tools/gripper_panel.py`（窗口与共享操作互斥）、`tools/arm_homing.py`（单臂路径检查、低速插值与反馈/停止）。离线验证命令：

```powershell
E:\Dobot\.venv\Scripts\python.exe -X utf8 -B -m unittest tests.test_arm_homing tests.test_gripper_panel tests.test_gripper_diagnostics
```
